# Iconos SVG de la documentación

[← README del proyecto](../../README.md)

Todos los iconos son archivos locales. Se incluyen nombres de tecnología y texto alternativo para no depender únicamente del color o de reconocer una marca.

## Logotipos Devicon

`javascript`, `html5`, `css3`, `react`, `vitejs`, `tailwindcss`, `threejs`, `supabase`, `postgresql`, `nodejs`, `git`, `github`, `vitest`, `playwright` y `eslint` proceden de Devicon v2.17.0. La [licencia MIT original](LICENSE) se conserva en esta carpeta. Las marcas pertenecen a sus titulares; mostrarlas no implica patrocinio.

El script [sync-doc-icons.mjs](../../scripts/sync-doc-icons.mjs) permite recuperar esos recursos desde la versión fijada.

## Pictogramas editoriales propios

`gsap`, `motion`, `router`, `zustand`, `lenis`, `tmdb`, `fiber`, `drei`, `lucide` y `ffmpeg` son identificadores gráficos creados para este README. **No son logotipos oficiales**. Sus títulos SVG lo indican explícitamente.

`purpose`, `map`, `ticket` y `gallery` identifican secciones del documento. No representan librerías ni dependencias instaladas.

Los SVG editoriales no cargan scripts, fuentes remotas ni imágenes externas. El banner y el mapa mental siguen el mismo criterio.
